# Xray Demo Project

This repository showcases a demo Xray project in Jira Cloud including demo User Stories for a Todo App, and their relevant Tests through to Test Execution.

---

## Project Overview

The following user stories are implemented and tested using Xray in Jira Cloud. The **Status** reflects the results of the executed test runs.

| User Story | Test                        | Status |
| ---------- | --------------------------- | ------ |
| Add a task | Add item functionality test | Passed |
| Delete a task | Delete task functionality test | Passed |
| Edit a task | Edit task functionality test | Failed |
| Mark task complete | Complete task functionality test | Passed |
| View tasks | View tasks functionality test | Passed |

---

## Test WorkFlow Overview

This demo project follows Xray's typical testing workflow.

1. User stories define requirements.
2. Tests created and linked to relevant stories.
3. Test executions contain test runs.
4. Test runs executed and marked as Pass/Fail.
5. Results are felected in the test coverage panel of each story.
